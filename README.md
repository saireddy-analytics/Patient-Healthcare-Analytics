# 🏥 Patient Healthcare Analytics

## 📌 Project Overview

Patient Healthcare Analytics is an institute-guided group project focused on analyzing Electronic Medical Records (EMR) data to understand patient visits, disease trends, doctor performance, treatment costs, laboratory results, billing, and insurance operations.

The project uses Excel, MySQL, Tableau, and Power BI to perform data analysis, calculate Key Performance Indicators (KPIs), and develop interactive dashboards.

## 🎯 Project Objectives

- Analyze patient demographics and hospital visits.
- Identify the most frequently diagnosed diseases.
- Understand disease trends across different age groups and months.
- Evaluate doctor and department performance.
- Analyze patient follow-up requirements.
- Monitor treatment costs and outcomes.
- Analyze laboratory test results.
- Understand billing and insurance claim status.
- Develop dashboards to support healthcare performance monitoring.
